# Источники мониторинга (утверждено 28.09.2026, обновлено 01.10.2026)

Только источники с высокой надёжностью, всего 13. Официальные идут первыми и служат для подтверждения фактов из СМИ.

## Официальные
1. RTA, новости: https://www.rta.ae/wps/portal/rta/ae/home/news-and-media/all-news (сайт отстаёт на несколько дней, свежее смотреть в X)
2. RTA в X: https://x.com/rta_dubai
3. Dubai Media Office: https://www.mediaoffice.ae/en/news (лента грузится скриптом, искать через поиск по site:mediaoffice.ae и X @DXBMediaOffice)
4. Dubai Police: https://www.dubaipolice.gov.ae/ (сайт часто не открывается для проверки — смотреть п.4а)
4а. Dubai Police в X: https://x.com/DubaiPoliceHQ (добавлено 01.10.2026; оперативные предупреждения о пробках, авариях, закрытых дорогах, новых правилах и штрафах. X напрямую не читается — искать через WebSearch по «DubaiPoliceHQ» + тема/дата и через СМИ, которые цитируют посты)
5. WAM: https://www.wam.ae/en (цены на топливо объявляются в последние дни месяца)
6. Salik: https://www.salik.ae/en/news
7. Parkin: https://www.parkin.ae/
8. Etihad Rail: https://www.etihadrail.ae/
9. Портал правительства ОАЭ: https://u.ae/en (только для проверки правил)
