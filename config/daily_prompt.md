# Ежедневная сводка Rentico — инструкция запуска

Запуск приходит в чат Claude, у которого есть доступ на запись в этот репозиторий. Сводка доставляется в Telegram-канал только через push нового файла в `digests/` (GitHub Actions пересылает его в канал). Без push в канал ничего не придёт.

ЦА: в первую очередь резиденты Дубая, во вторую — туристы.

## 0. Продлить расписание (первым делом)
Запуски идут цепочкой разовых напоминаний на 7 дней вперёд. В начале каждого запуска:
- через list_triggers (include_completed: false) посмотри напоминания с именем «Rentico: сводка ГГГГ-ММ-ДД»;
- убедись, что на каждый из ближайших 7 дней (считая завтра) есть напоминание; недостающие создай инструментом send_later:
  - at: ГГГГ-ММ-ДДT03:52:00Z (07:52 по Дубаю),
  - name: «Rentico: сводка ГГГГ-ММ-ДД»,
  - initiation: human_schedule,
  - message: «Ежедневная сводка Rentico. Выполни инструкцию из config/daily_prompt.md в репозитории chesssnokovaa-dev/rentico-news.»

## 1. Подготовка
- Репозиторий: /home/claude/rentico-news. Если клона нет — git clone https://github.com/chesssnokovaa-dev/rentico-news /home/claude/rentico-news; если push отклоняется, вызови add_repo (owner chesssnokovaa-dev, repo rentico-news, access push) и повтори.
- git pull --rebase origin main.
- Прочитай config/sources.md (13 источников, только их; средняя надёжность, Reddit, форумы — не используются) и archive/news.jsonl (уже отправленное, для отсечения дублей).
- Текущая дата и время — инструментом текущего времени, работай по времени Дубая (Asia/Dubai).

## 2. Сбор
Новости за последние 24 часа (только Дубай или все ОАЭ):
- ПДД: новые правила, штрафы, black points, камеры, лимиты скорости
- Дороги: развязки, мосты, съезды, перекрытия, ремонт, открытие трасс
- Аренда авто: требования к правам туристов и резидентов, депозиты, страховка, возраст водителя
- Покупка и владение: регистрация, техосмотр, страховка, цены на топливо (обновляются в конце месяца)
- Salik, Parkin, платные парковки, тарифы и зоны
- Общественный транспорт: метро, трамвай, автобусы, Nol, Etihad Rail, новые линии и станции
- Такси, Careem, Uber, роботакси, летающие и водные такси
- Визовые и резидентские изменения, если влияют на права или аренду авто
- События, влияющие на трафик: праздники, выставки, дожди, закрытые дороги
WebSearch + WebFetch. Лента rta.ae отстаёт — проверяй mediaoffice.ae и СМИ со ссылкой на RTA. Для полиции ищи посты @DubaiPoliceHQ через WebSearch (сайт dubaipolice.gov.ae часто не открывается).

## 3. Фильтр
Оставляй только то, что одновременно: реально новое; касается Дубая или всех ОАЭ; практически полезно (меняет правила, деньги, маршруты, сроки); не совпадает по сути с archive/news.jsonl.
Факты из СМИ подтверждай первоисточником (RTA, Dubai Media Office, Dubai Police, WAM, Salik, Parkin, Etihad Rail, u.ae); если не найден — «первоисточник не найден». Не выдумывай цифры. Расхождения между источниками отмечай. Максимум 7 новостей, по важности.

## 4. Новостей нет
Ничего не коммить, в канал ничего не отправлять. В чат — одна строка «Новостей нет». Исключение — 1-е число (п.6).

## 5. Новости есть
Файл digests/ГГГГ-ММ-ДД.md (дата по Дубаю), на русском, кратко. Разметка: только **жирный**, обычный текст, эмодзи срочности, голые URL. Без таблиц и заголовков через #.

**Транспорт Дубая и ОАЭ · ДД.ММ.ГГГГ**

Для каждой новости:
**N. Заголовок в одну строку**
Суть: 2–3 предложения — что изменилось, с какой даты, для кого.
Цифры: суммы, даты, тарифы (если есть; иначе строку не пиши).
Источник: ссылка (+ «Первоисточник:» ссылка, если новость из СМИ).
Для кого: резиденты / туристы / все.
Срочность: 🔴 горячее (публиковать сегодня) / 🟡 на неделе / 🟢 вечнозелёное.
Идеи контента: 2–3 угла подачи (пост, Reels, статья в блог Rentico, обновление существующей статьи) + связь с арендой авто, если естественная.

В конце: **Топ-1 дня:** какую новость брать в работу первой и почему.

В archive/news.jsonl — по строке на новость:
{"date":"ГГГГ-ММ-ДД","title":"...","topic":"...","key":"короткий ключ сути","source":"url","primary_source":"url или null"}

Один коммит (digests/ + archive/), push в main, затем проверь `git fetch origin main && git log origin/main -1` и через ~60 с статус запуска «Send digest to Telegram» в GitHub Actions (api.github.com/repos/chesssnokovaa-dev/rentico-news/actions/runs?per_page=1).

## 6. 1-е число месяца
Добавь в конец сводки блок **Источники:** 1–3 предложения — какие из источников за месяц ничего не дали и что стоит добавить (только официальные или СМИ с высокой надёжностью). Если новостей нет — отправь файл только с заголовком и этим блоком.

## 7. Ответ в чат
Первая строка: «✅ Отправлено в канал» или «⚠️ Не отправлено: <ошибка дословно>». Затем полный текст сводки.

## Правила
Не больше 7 новостей. Без блока трендов из сообществ. Не выдумывать цифры и даты. Не менять .github/, scripts/ и остальные файлы config/ без просьбы пользователя.
